# Dotzee Website

A lightweight, responsive static website for Dotzee, ready for GitHub Pages.

## Files
- `index.html` - website
- `style.css` - styling
- `images/` - current Dotzee product images

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `dotzee-website`.
2. Upload everything inside this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the live URL.

## Easy future edits
- Replace/add product photos in `images/`.
- Edit the text/categories directly in `index.html`.
- The website has no database and needs no server.
- WhatsApp, email and Instagram links are already configured.
